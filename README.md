## 🌌 Présentation

Ce portfolio est conçu comme un univers cosmique abstrait où les applications, les données et l'infrastructure gravitent autour d'une géométrie centrale cristalline interactive en 3D (React Three Fiber / Three.js).

Il a été développé avec une exigence de fidélité stricte aux sources publiques vérifiées (profil GitHub [@NaelleNangmo](https://github.com/NaelleNangmo/NaelleNangmo), dépôts de code réels, cursus académique), sans aucune invention de métriques, ni de chiffres de performance infondés.

---

## 🛠️ Stack Technique

- **Framework Web** : [Next.js 14](https://nextjs.org/) (App Router)
- **Langage** : [TypeScript](https://www.typescriptlang.org/) (Mode strict, 100% typé)
- **Rendu 3D & WebGL** : [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) + [@react-three/drei](https://github.com/pmndrs/drei)
- **Styles & Design System** : [Tailwind CSS](https://tailwindcss.com/) avec palette cosmique personnalisée
- **Animations DOM** : [Framer Motion](https://www.framer.com/motion/) & Transitions CSS hardware-accelerated
- **Iconographie** : [Lucide React](https://lucide.dev/)
- **Internationalisation (i18n)** : Système bilingue dynamique Français / Anglais sans rechargement de page

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 18+ ou 20+
- npm 9+

### Installation des dépendances
```bash
npm install
```

### Lancement du serveur de développement
```bash
npm run dev
```
Le portfolio sera accessible sur [http://localhost:3000](http://localhost:3000).

### Vérification des types TypeScript
```bash
npx tsc --noEmit
```

### Compilation pour la production
```bash
npm run build
npm run start
```
